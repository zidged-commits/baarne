# BAARNE licensing scope

Decision approved by the project owner on 2026-10-16:

- **Original BAARNE software: `AGPL-3.0-only`.** The full GNU Affero General
  Public License version 3 text is in [LICENSE](LICENSE). This is version 3
  **only**, not an automatic permission to use a later license version.
- **Original BAARNE manifesto and documentation: `CC-BY-SA-4.0`.** The full
  legal code is in [LICENSES/CC-BY-SA-4.0.txt](LICENSES/CC-BY-SA-4.0.txt).

These grants apply only to original BAARNE material for which the grantor has
the necessary rights. They do not assert copyright in uncopyrightable facts,
algorithms or material where no copyright subsists; they do not transfer title
from contributors or create rights in someone else's work.

## Scope by material

| Material | Applicable selection / boundary |
| --- | --- |
| Original source in `apps/`, `packages/`, `services/`, `blockchain/`, `scripts/`, `tests/`, `experiments/`, plus original build/config/schema material | AGPL-3.0-only, except separately identified third-party material. Original code snippets embedded in documentation use this software selection. |
| Original prose in repository Markdown/documentation, including the BAARNE manifesto, README, contributor/security instructions and authored reports | CC-BY-SA-4.0, except quotations, third-party text and code snippets as above. |
| Dependencies, vendored code, upstream license texts/notices, quoted specifications and third-party assets | Their existing licenses/rights remain applicable. A root license does not relicense them. Preserve upstream notices and examine obligations for the actual combination/distribution. |
| Generated evidence, histories, signatures, screenshots, binary artifacts, archives and factual data | No blanket relicense or ownership claim over the container/data. Original software/prose components retain their applicable selection; third-party rights, privacy, confidentiality and original artifact notices remain separate. |
| User records, profiles, messages, consent data, keys, recovery material and held operational evidence | Not granted for public use or disclosure by this decision. A software license is not consent to publish personal data or secrets. |
| BAARNE name, logos and other marks | No trademark license or endorsement is granted by this scope notice. |

The original manifesto includes `docs/governance/BAARNE_MANIFESTO.md`; keep its
existing authorship/date/version and distinguish adaptations from that original.
Software/examples embedded in a prose document remain subject to the software
selection, not a silent permissive alternative. The license texts themselves
retain their own existing terms; they are not rewritten as BAARNE-authored prose.

## Attribution and adaptations

Retain existing copyright, author and attribution notices. For original BAARNE
documentation without a more specific attribution, identify the **BAARNE project**
as the source, identify the document/title/version/date where supplied, refer to
this scope and CC BY-SA 4.0, and indicate changes. No legal entity or new
copyright ownership assignment is invented by that project attribution.

Follow the actual license texts for source delivery, required notices and
share-alike obligations. This summary adds no bespoke restriction, commercial
ban, fee prohibition or requirement that everyone contribute to one central
repository. AGPL network-source obligations concern the covered software and
its corresponding source; they do not make private user data public.

The AGPL appendix includes a generic example using an "or later" notice. That
example is not the BAARNE grant: this project's explicit selection is
**AGPL-3.0-only**. Future contributions intended for inclusion must respect this
code/document split unless the owner explicitly accepts a separately licensed
component with compatible terms. No CLA or copyright assignment is imposed.

## Historical source and archives

Frozen protocol source bytes, old reports and old capsule fingerprints are not
rewritten to add license headers or change historical claims. This notice gives
the current selection for original material in this checkout; it does not
fabricate an earlier license decision or alter archived manifests. Historical
statements such as "license unresolved" describe their creation-time status.
New capsule builds include these license texts/scope and current metadata.
