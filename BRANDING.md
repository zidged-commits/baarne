# baarne brand writing

Write the project name as **baarne**, entirely lowercase, including at the
start of a sentence, in headings, page titles, metadata and accessibility labels.
The existing wordmark may appear as **baarne.**, with its decorative final dot.
Do not apply CSS uppercase or capitalization transforms to the name.

This is a presentation convention, not a protocol migration. Existing technical
identifiers, case-sensitive repository paths/URLs, upstream notices, historical
evidence and the byte-pinned r12 delivery keep their exact spelling and bytes.
For example, `BAARNE_REFERENCE_V1` remains an unchanged protocol identifier.
